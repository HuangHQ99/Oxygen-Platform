# W02-03 预发布部署、备份与恢复

本文只适用于马来西亚 `ap-southeast-5` 的 Oxygen 单节点预发布环境。它不是生产高可用方案。
所有命令使用 IAM Identity Center 临时会话；不得把账号号、令牌、数据库密码、Cognito 客户端秘密或
CloudFront 源站校验值写入仓库、工单或聊天。

## 费用边界

2026-11-24 通过 AWS Pricing API 实查，马来西亚按需 `t4g.micro` 为 `0.0095 USD/小时`，按 730
小时约 `6.94 USD/月`。加上公网 IPv4、20 GiB gp3、Secrets Manager、少量 S3/ECR/CloudFront
用量后，当前低流量估算约 `13–15 USD/月`。20 USD 是 80% 预测和 100% 实际邮件告警阈值，不是
自动停机上限。流量、镜像、备份增长或 AWS 调价会改变结果。

## 首次部署

1. `aws sso login --profile oxygen-preprod`，再用 `aws sts get-caller-identity` 确认临时会话。
2. 运行全仓门禁和两个 `linux/arm64` Docker 构建。
3. `cdk diff` 审核资源和 IAM 权限；首次账号执行 `cdk bootstrap`，随后 `cdk deploy`。三个参数通过
   当前进程注入：费用邮箱、至少 32 位随机源站值、全局唯一 Cognito 小写域名前缀。
4. 从 CloudFormation 输出取得两个 ECR URI、实例 ID和公网入口。镜像使用 Git commit 短 SHA
   作为不可变标签，同时更新 `stable`；不得只推 `latest`。
5. 通过 Systems Manager 执行 `sudo systemctl restart oxygen-runtime`。运行脚本会读取
   Secrets Manager 与 Cognito 配置、迁移数据库、检查 readiness；失败时恢复上一组镜像。
6. 验证 CloudFront HTTPS、未登录 401／登录跳转、API readiness、A/B 客户隔离、电脑与手机布局；
   直接访问源站必须返回 403。

## 日常发布与回退

日常发布只构建、推送同一 commit 标签并在实例运行：

```bash
sudo /opt/oxygen/runtime/deploy.sh COMMIT_TAG
```

脚本会保留当前容器引用，在新 API 180 秒内未达到 readiness 时自动重启上一组镜像。若新版本已
就绪但业务验收失败，查阅 `/opt/oxygen/current-release` 及 ECR 标签，再以已知良好标签重新运行
同一命令。数据库迁移必须保持向后兼容；镜像回退不会自动回退 Flyway。

## 备份与显式恢复

`oxygen-backup.timer` 每天 19:00 UTC（马来西亚次日 03:00，带 0–15 分钟随机延迟）生成 PostgreSQL
custom-format dump，上传到加密、版本化且禁止公开访问的 S3 bucket。对象保留 35 天，旧版本保留
7 天。检查方式：

```bash
systemctl status oxygen-backup.timer
sudo systemctl start oxygen-backup.service
journalctl -u oxygen-backup.service --since today
```

恢复是破坏性操作，不由定时任务或发布脚本自动执行。先确认目标备份、当前环境与变更窗口，再运行：

```bash
sudo /opt/oxygen/runtime/restore.sh s3://BUCKET/postgres/TIMESTAMP.dump
```

脚本要求人工输入 `RESTORE`，随后重建预发布数据库。恢复后重启 API，核对 Flyway、readiness、登录、
两客户隔离和关键记录。首次云部署后必须实际完成一次“手工备份 → 新建临时验证库恢复 → 核对”演练；
在该演练前只能声明备份入口已部署，不能声明恢复能力已验证。

## 基础设施回退与保留项

CloudFormation 失败会自动回滚本次堆栈操作。删除堆栈不是常规回退手段：Cognito 用户池、ECR、
Secrets Manager 和备份 bucket 使用保留策略，避免误删身份、镜像和备份，后续需按明确的数据处置
授权单独处理。EC2 根盘随实例替换可能丢失，因此 S3 备份和恢复演练是进入真实业务数据前的门槛。
