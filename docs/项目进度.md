## 已确认业务决定

2026-11-22，项目负责人确认以下规则，适用于后续需求、原型及实现。

- 本次样本 GA Code 以资产表格为准。历史报告短号、重号和位置差异保留为数据质量示例。Oxygen 以 QR Code／RFID 作为主要现场识别方式，GA 保存为参考编号。
- 故障描述由现场工程师裁定。属于 checklist 的故障在对应项直接显示异常，范围外故障记录在 Remark。报告须呈现两者。该规则确认了裁定人，历史样本第 15 项的具体故障仍保留来源差异。
- 实现建议为标签关联稳定资产 ID、Remark 显式故障标记，原型阶段验收。RFID 读写器及 Web 接入方式待硬件选型验证。
- W01-02 签认顺序为服务商工程师提交、服务商复核确认、服务商签发正式报告、客户在 Oxygen 外对导出的 PDF 预留位置签证。服务商通过登录账号点击确认并保存姓名、职位、服务器时间和版本；客户无需 Oxygen 账号。客户已签 PDF 不上传或归档到 Oxygen，平台不跟踪客户签署状态。
- 报告保留逐设备记录，并按同一客户、同一站点、同一期次、同一设备类型汇总，覆盖现场属于本次范围的全部同类设备。取消、延期和未执行设备保留在覆盖清单中。
- W01-03 角色收敛为服务商管理员、服务商维保负责人、服务商现场工程师。末端客户不设账号；服务商管理员合并组织、授权和资产管理；服务商维保负责人合并检查表、计划、复核和签发；不设置独立审计查看角色，但审计能力保留。
- 同一账号兼任维保负责人和现场工程师时，可以复核本人执行记录并签发包含本人执行记录的报告；提交、复核和签发分别保存人员、职位、服务器时间及版本记录。
- 一个客户可以拥有多个数据中心。人员授权可覆盖该客户全部数据中心或指定数据中心；计划可跨同一客户的多个已授权数据中心批量发起，但工单和报告按数据中心分别生成。
- W02-01 技术基线确定为 Java 21、Spring Boot 模块化单体、Vue 3 + TypeScript + Vite 响应式 Web、PostgreSQL + Flyway、Maven Wrapper + pnpm 单仓。手机和电脑共用一套 Web 应用；V1 不增加 UniApp 原生壳。详见 [ADR-001](ADR-001技术栈与单仓基线.md)。

业务规则已写入 AGENTS.md、W01-01 核对表和 W01-02 流程文档。W01-01 已验收；历史来源差异和待业务定义事项按下表继续跟踪。

- `./mvnw --offline --batch-mode --no-transfer-progress -DskipITs verify`：6 个 Maven 模块构建成功，Checkstyle 0 违规，单元测试通过。
